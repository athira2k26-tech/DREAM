# Dream Tonight 🌙

### Team Name: EVOX

### Team Members

* Team Lead: Athira AP - SNMIMT
* Member 2: Aryananda Ajith - SNMIMT

### Project Description

Dream Tonight is a completely useless but entertaining dream prediction website that pretends to scan your subconscious and predict what you will dream about tonight.

Users enter their name, choose their mood, and optionally tell the Dream Machine something about their day. The website then performs a dramatic fake "subconscious scan" before revealing a randomly generated dream or nightmare.

With magical visuals, cinematic animations, ridiculous predictions, fake scientific probabilities, and questionable AI logic, Dream Tonight turns the simple act of going to sleep into an unnecessarily complicated experience.

### The Problem (that doesn't exist)

People go to sleep without knowing what they are going to dream about.

This creates a completely unnecessary problem:

**"What if I don't know my dream before I dream it?"**

There was absolutely no demand for a solution to this problem.

We solved it anyway.

### The Solution (that nobody asked for)

Dream Tonight uses highly advanced technology such as:

* Random numbers
* Questionable science
* The user's mood
* Three tired neurons
* The moon
* Suspicious algorithms

to "predict" the user's dream.

After a dramatic subconscious scan, the system reveals a completely fake dream prediction along with a scientifically meaningless probability.

Because apparently, knowing your future dream before sleeping is now a software requirement.

# Installation

No complicated installation is required.

Clone the repository:

```bash
git clone <your-github-repository-url>
```

Open the project folder in Visual Studio Code.

No backend, database, API key, or server setup is required.

# Run

Open `index.html` directly in a browser, or use the Live Server extension in Visual Studio Code.

The project runs entirely in the browser.
